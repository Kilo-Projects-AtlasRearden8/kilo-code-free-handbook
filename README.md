# Kilo Code Free Handbook

A beginner-friendly manual (Markdown docs + static HTML site) on using **Kilo Code** for free: installing the CLI and VS Code extension, free models with no account, headless runs, modes and agents, safe permissions, checking your cost is $0, and troubleshooting. Plain English, step by step, with a glossary and checklists.

Written by **Dylan Asdale** of **Asdale Dynamics, LLC** — a registered nurse turned AI author who explains AI "like a friend would": plain English, step by step, never condescending.

## Quick start

You need [Node.js](https://nodejs.org). Then:

```bash
npm install
npm run build
```

This reads the Markdown files in `docs/` and writes HTML files to `site/`. Open `site/index.html` in your browser to read the handbook.

To run the tests:

```bash
npm test
```

To syntax-check the build script:

```bash
npm run lint
```

## Who this is for

Anyone who wants to code with AI without paying for a subscription. Writers, small-business owners, healthcare workers learning AI (education only — never medical advice), and beginners of every kind. No prior programming experience required.

## Local-first, privacy-first

This handbook and the site it builds are **local-first**: you can read, build, and host everything on your own computer. We never ask for API keys, passwords, or personal data, and you should never paste them into this guide or into Kilo unless you fully understand what you're doing.
