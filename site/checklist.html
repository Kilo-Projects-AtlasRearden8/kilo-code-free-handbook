Checklists

Print these or copy them into your notes. Work through each checklist as you set up and use Kilo Code.

Checklist 1: Installing Kilo

  • [ ] node --version prints a version number
  • [ ] kilo --version prints a version number (or npx kilo --help works)
  • [ ] You ran kilo once in a practice folder
  • [ ] You know where to find kilo --help

Checklist 2: Free models with no account

  • [ ] kilo models list shows available models
  • [ ] You selected a free model with kilo config set model
  • [ ] You ran kilo without signing in
  • [ ] You checked your cost and saw $0

Checklist 3: Safe permissions

  • [ ] You are working in a practice folder or a git repo
  • [ ] You can run git diff to review changes (or you backed up your files)
  • [ ] You have not pasted any keys, passwords, or personal data
  • [ ] You read every diff before accepting
  • [ ] You rejected at least one suggestion just to practice

Checklist 4: Headless run

  • [ ] You ran a headless kilo command with --prompt
  • [ ] You checked the changed files afterward
  • [ ] You saved the command in a script for reuse
  • [ ] You reviewed changes before using --yes on real code

Checklist 5: Cost is $0

  • [ ] kilo cost (or equivalent) runs without error
  • [ ] The output shows $0.00
  • [ ] You checked the VS Code panel too, if you use the extension
  • [ ] You know which model you're using and that it's free

Checklist 6: Modes and agents

  • [ ] You asked one question in chat mode
  • [ ] You accepted one edit in edit mode after reading the diff
  • [ ] You tried agent mode on a practice folder (if available)
  • [ ] You rejected at least one suggestion you didn't understand

Master checklist: you're ready to use Kilo Code for free

  • [ ] CLI or VS Code extension installed
  • [ ] Free model selected, no account required
  • [ ] Safe permission habits in place
  • [ ] Cost verified at $0
  • [ ] At least one successful task completed in a practice folder

When every box is checked, you're using Kilo Code for free, safely, and on your own terms.
