Installing the Kilo VS Code Extension

If you prefer coding inside Visual Studio Code (VS Code), Kilo works as an extension there too. You get the same AI coding help inside your editor, with the same free models available.

Step 1: Install VS Code

Download VS Code for free from code.visualstudio.com. Install it like any other app, then open it.

Step 2: Open the Extensions view

In VS Code:

  1. Click the Extensions icon on the left activity bar (it looks like four squares, one slightly detached). Or press Ctrl+Shift+X (Windows/Linux) or Cmd+Shift+X (macOS).
  2. In the search box at the top, type Kilo.
  3. Find the extension published by the Kilo team (look for the official Kilo Code extension).
  4. Click Install.

Step 3: Enable the extension

After installation, reload VS Code if prompted. You should see a Kilo icon in the activity bar or a Kilo panel in the sidebar. Click it to open Kilo.

Step 4: Sign in (optional)

Kilo may ask you to sign in to use account features. Free models are available without an account — choose "Continue without signing in" or skip sign-in if you only want free models.

Step 5: Your first chat in VS Code

  1. Open any folder in VS Code (File > Open Folder).
  2. Open the Kilo panel.
  3. Type a plain-English request, for example:

> "Explain what this file does."

or

> "Add a function that calculates the total price."

  1. Kilo will suggest code changes. Review each suggestion carefully before accepting. See Safe permissions for how to review safely.

Uninstalling

To remove the extension:

  1. Open the Extensions view (Ctrl+Shift+X / Cmd+Shift+X).
  2. Search for Kilo.
  3. Click the gear icon next to Kilo and choose Uninstall.

Quick checklist

  • [ ] VS Code is installed and opens
  • [ ] The Kilo extension is installed from the Extensions view
  • [ ] The Kilo panel opens in the sidebar
  • [ ] You have sent one message in the Kilo panel

If the extension doesn't appear

  • Reload the window: Ctrl+Shift+P (or Cmd+Shift+P), type Developer: Reload Window, and press Enter.
  • Check for updates: Extensions view > ... > Check for Updates.
  • See Troubleshooting if it still doesn't show up.
