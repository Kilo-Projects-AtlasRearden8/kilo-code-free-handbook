# STATUS

Kilo Code Free Handbook — build status, how to run, and verification results.

## What was built

A beginner manual on using Kilo Code for free, delivered as Markdown docs plus a static HTML site. Plain English, step by step, with a glossary and checklists. Written by Dylan Asdale of Asdale Dynamics, LLC.

**Markdown docs (`docs/`):**

1. index.md — Welcome and how to use the handbook
2. installing-the-cli.md — Installing the Kilo CLI (`node`, `npm install -g kilo`, `npx kilo`)
3. installing-the-vs-code-extension.md — Installing the VS Code extension
4. free-models-no-account.md — Free models, no account required
5. headless-runs.md — Running Kilo headlessly from the terminal
6. modes-and-agents.md — Chat, edit, and agent modes
7. safe-permissions.md — Reviewing diffs, never pasting secrets, undoing changes
8. checking-cost-is-zero.md — Verifying your cost stays $0
9. troubleshooting.md — Common problems and plain-English fixes
10. glossary.md — Plain-English definitions
11. checklist.md — Step-by-step checklists, including a master checklist

**Static site (`site/`):** 11 HTML pages + `style.css`, generated by `build.js` from `docs/`. Internal links rewritten from `.md` to `.html`. Every page carries the site title, navigation, Asdale Dynamics credit, and the copyright line.

**Tooling:** `build.js` (dependency-free Markdown-to-HTML builder), `tests/build-test.js` (36 assertions), `package.json` with `build`, `test`, and `lint` scripts, `.gitignore` for generated output.

**Legal:** `LICENSE` (MIT, Copyright (c) 2026 Asdale Dynamics, LLC), `README.md` credits Asdale Dynamics, LLC.

## How to run it

Requires Node.js (tested with v20.19.2).

```bash
# Build the static HTML site from docs/
npm run build

# Open the handbook
open site/index.html   # macOS
# or just open site/index.html in your browser

# Run the test suite
npm test

# Syntax check the JS files
npm run lint
```

`npm run build` writes to `site/` and prints each page produced. `site/` is generated output from `docs/` (gitignored) and is safe to re-build at any time.

## Known gaps

- CLI command examples (`kilo models list`, `kilo config set model`, `kilo cost`, `kilo --prompt`, `kilo auth login`) match common Kilo shapes but flag names vary by version; each page tells the reader to run `kilo --help` for their exact version.
- The build script is dependency-free and handles common Markdown (headings, lists, tables, code blocks, links, bold, italic) but not every Markdown edge case; if you add unusual Markdown to `docs/`, check the HTML output.
- `site/` is generated output and not committed; re-run `npm run build` after editing `docs/`.
- No `.github/workflows` files were added, per project constraints.
- This handbook describes Kilo Code as a third-party tool; Kilo features and pricing change over time — verify against current Kilo documentation.
