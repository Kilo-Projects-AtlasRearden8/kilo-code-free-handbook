# Glossary

Plain-English definitions for terms used in this handbook. If you see a word that isn't here, let us know and we'll add it.

**AI coding assistant** — A tool that helps you write, understand, and change code using artificial intelligence. Kilo Code is one example.

**Agent** — A mode where Kilo plans and carries out a multi-step task across several files, asking for approval at key points.

**CLI (Command Line Interface)** — A program you run from the terminal by typing commands, rather than clicking buttons in an app.

**Commit** — In git, a saved snapshot of your files. Commits let you go back to earlier versions of your work.

**Context window** — How much text (code, conversation, files) an AI model can "remember" at one time. Smaller context windows mean the model forgets earlier parts of your code.

**Diff** — A before-and-after view of changes to a file. Added lines are usually shown in green, removed lines in red.

**Extension** — A add-on for VS Code that gives it new features. The Kilo extension brings Kilo into VS Code.

**Free model** — An AI model you can use without paying, usually within daily or monthly limits.

**Headless** — Running a program from the terminal with no windows or graphical interface. Good for scripts and servers.

**Markdown** — A simple way to format text (headings, lists, links) using plain characters like `#` and `*`. This handbook is written in Markdown.

**Mode** — A behavior setting for Kilo, such as chat mode (questions and answers) or edit mode (suggesting file changes).

**npx** — A tool that comes with Node.js and runs a package without installing it globally. `npx kilo` runs Kilo without a permanent install.

**Node.js** — A runtime that lets you run JavaScript tools like Kilo on your computer.

**PATH** — A list of folders your terminal searches when you type a command. If Kilo isn't on your PATH, your terminal won't find it.

**Repository (repo)** — A folder tracked by git, including its history of changes.

**Static site** — A website made of HTML, CSS, and JavaScript files that don't need a server or database to run. The site built from this handbook is static.

**VS Code** — Visual Studio Code, a free code editor from Microsoft.
