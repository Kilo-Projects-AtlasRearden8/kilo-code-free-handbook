## Who this is for

You do not need to be a software engineer to use this guide. If you can open a terminal and copy-paste a command, you can use Kilo Code. We wrote it for:

- Writers and authors exploring AI coding tools
- Small-business owners automating everyday work
- Healthcare workers learning AI (education only — never medical advice)
- Anyone who wants to code with AI without paying for a subscription

## Local-first, privacy-first

This handbook and the site it builds are **local-first**: you can read, build, and host everything on your own computer. We never ask for API keys, passwords, or personal data, and you should never paste them into this guide or into Kilo unless you fully understand what you're doing.

## How to read this handbook

Start at the top and work down, or jump to the section you need right now. Each page is written to stand alone. Follow the steps in order, and use the checklists at the end to confirm you're done.
